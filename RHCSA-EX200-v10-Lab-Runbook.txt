Objetivo
--------
Reproduzir, do zero, o ambiente:

GitHub
  |
  | clone / pull
  v
bastion.lab.test           192.168.100.10
  |  Git / Ansible / lab
  |
  +---- SSH / Ansible ---- servera.lab.test  192.168.100.11
  |
  +---- SSH / Ansible ---- serverb.lab.test  192.168.100.12

Rede libvirt:
  rhcsa-lab
  192.168.100.0/24
  gateway 192.168.100.1
  bridge virbr-rhcsa

Host:
  KVM/libvirt
  snapshots/console

Premissas desta rotina
----------------------
1. Host KVM principal: Ubuntu 24.04 Desktop.
2. VMs: RHEL 9.8, alinhadas ao projeto atual.
3. Método utilizado: imagem-base QCOW2.
4. A imagem-base já foi baixada para ~/Downloads:
     rhel-rhcsa-base-v1.qcow2
     rhel-rhcsa-base-v1.qcow2.sha256
5. A imagem-base possui aproximadamente 30 GiB de tamanho virtual.
6. Usuário padrão do laboratório: student.
7. Senha local de laboratório usada nesta rotina: redhat.
8. Execute os comandos de cada bloco SOMENTE na máquina indicada.
9. Não inicialize a imagem-base diretamente.
10. Não crie filesystem/partições nos discos extras de servera/serverb.

BLOCO 2 - HOST KVM/LIBVIRT - POOL DE STORAGE
======================================================================

# Verifique primeiro:

sudo virsh -c qemu:///system pool-list --all

# Se o pool "default" JÁ existir, apenas tente ativá-lo:

sudo virsh -c qemu:///system pool-start default 2>/dev/null || true
sudo virsh -c qemu:///system pool-autostart default 2>/dev/null || true

# Se o pool default NÃO existir, crie:

sudo mkdir -p /var/lib/libvirt/images

if ! sudo virsh -c qemu:///system pool-info default >/dev/null 2>&1; then
  sudo virsh -c qemu:///system \
    pool-define-as default dir \
    --target /var/lib/libvirt/images

  sudo virsh -c qemu:///system pool-start default
  sudo virsh -c qemu:///system pool-autostart default
fi

sudo virsh -c qemu:///system pool-info default
