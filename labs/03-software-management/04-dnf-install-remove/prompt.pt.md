No `servera`, o repositório `rhcsa-base` já está configurado.

1. Instale `rhcsa-toolkit` com DNF.
2. Instale `rhcsa-temp` com DNF.
3. Verifique os dois pacotes com RPM.
4. Remova `rhcsa-temp` com DNF.
5. Ao final, `rhcsa-toolkit` deve permanecer instalado na versão `1.0-1`
   e `rhcsa-temp` deve estar ausente.
