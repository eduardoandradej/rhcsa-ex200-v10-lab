No `servera`:

1. Bloqueie a senha de `departed1` e expire a conta imediatamente usando data de expiração `1`.
2. Configure `serviceacct` para usar `/sbin/nologin`.
3. Configure `tempcontract` para expirar 30 dias a partir de hoje.
4. `recoveruser` começa bloqueado e expirado. Desbloqueie sua senha e remova a data de expiração.

Não remova nenhuma das quatro contas.
