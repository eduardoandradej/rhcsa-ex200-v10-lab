On `servera`, create executable script
`/home/student/rhcsa-lab/obj04-05/argloop.sh`.

Requirements:

1. For each received argument, print:
   `ARG:<value>`
2. Preserve each argument as one unit, including arguments containing spaces.
3. Preserve original order.
4. With zero arguments:
   - print `NO-ARGS`
   - exit with code `1`.
5. With one or more arguments, exit with code `0`.

The script must accept a variable number of arguments.
