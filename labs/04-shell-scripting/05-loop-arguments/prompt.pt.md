No `servera`, crie o script executável
`/home/student/rhcsa-lab/obj04-05/argloop.sh`.

Requisitos:

1. Para cada argumento recebido, imprima uma linha:
   `ARG:<valor>`
2. Preserve cada argumento como uma unidade, inclusive quando contiver espaços.
3. Preserve a ordem original.
4. Com zero argumentos:
   - imprima `NO-ARGS`
   - encerre com código `1`.
5. Com um ou mais argumentos, encerre com código `0`.

O script deve aceitar uma quantidade variável de argumentos.
