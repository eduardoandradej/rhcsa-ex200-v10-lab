# v1.4.12 — Objective 03 local repository permission hotfix

Runtime diagnostics proved that the Objective 03 failure was a Unix path
permission problem, not an Internet outage and not a repository-build failure.

`repomd.xml` existed and was readable as root, but `/var/lib/rhcsa-lab` was
`0700 root:root`. The student account could not traverse the shared parent, so
DNF could not open the `file:///var/lib/rhcsa-lab/obj03/...` repository.

v1.4.12 makes the contract deterministic:

- `/var/lib/rhcsa-lab` is root-owned `0711`: known paths are traversable, while
  directory listing remains denied to ordinary users;
- the OBJ03 repository subtree remains `0755`;
- after repository creation, both base and errata `repomd.xml` are explicitly
  tested for readability while executing as `student`;
- a release gate protects this requirement.

The integration runner is unchanged from the applied v1.4.10 line. The
previously proposed v1.4.11 runner change is not included.
