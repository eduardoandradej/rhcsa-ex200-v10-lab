# v1.8.1 — OBJ12-02 grader privileged-log hotfix

Runtime integration exposed a grader-only defect in `obj12-02`.

The reference solution successfully configured HTTPD, cron, tmpfiles and
rsyslog. During grading, however, the remote checker attempted to read
`/var/log/ops12.log` directly as the unprivileged `student` account.

On RHEL, the rsyslog-created log can be non-readable by `student`. The remote
checker therefore raised `PermissionError` before it could print its JSON
result. The controller consequently reported:

`grader retornou saída JSON inválida`

v1.8.1 changes only the privileged log inspection path. The grader now reads
the log with non-interactive sudo:

`sudo -n cat /var/log/ops12.log`

The learner task and expected final state are unchanged.
