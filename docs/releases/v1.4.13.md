# v1.4.13 — Objective 05 non-interactive pause hotfix

The global reference regression failed at `obj05-04` during lab preparation.

The setup used Ansible's `pause` module for a two-second delay so CPU and
memory metrics could accumulate. In the integration harness, `lab start` is
captured through a non-interactive subprocess with no controller TTY. The
`pause` action attempted terminal I/O and failed with:

`OSError: [Errno 25] Inappropriate ioctl for device`

This was not a server-side process, resource-monitoring, or RHEL issue.

v1.4.13 replaces the two OBJ05 timing-only `ansible.builtin.pause` tasks with
`/usr/bin/sleep 2` through `ansible.builtin.command`, marked
`changed_when: false`.

The same proactive correction is applied to `obj05-10`, which used the same
TTY-dependent pause pattern and would otherwise fail later in the same global
regression.

A release gate now rejects reintroduction of `ansible.builtin.pause` in these
non-interactive metric-wait setups.

No student-facing task, grader requirement, or process-control objective is
changed.
