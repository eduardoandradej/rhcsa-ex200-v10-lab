# v1.4.0 — Objective 08 Storage

Adds 12 labs for basic storage and LVM.

Safety is part of the release, not an external procedure:

- `/dev/vda` is hard denied;
- destructive labs are restricted to snapshot-tested `servera`;
- scratch disks are allowlisted with expected size ranges;
- every destructive setup requires a blank-device preflight;
- every destructive finish restores the saved fstab and resets only the
  authorized scratch devices;
- full integration grows from 60 to 72 labs.

Runtime integration is required before tagging the release stable.
