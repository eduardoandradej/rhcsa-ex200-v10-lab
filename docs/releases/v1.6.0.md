# v1.6.0 — Objective 10 SELinux & firewalld

Adds nine runtime-gradeable labs for SELinux and network security.

Key coverage:

- SELinux enforcing/permissive and persistent mode configuration;
- process and file contexts;
- persistent file-context policy with `semanage fcontext`;
- policy-aware relabeling with `restorecon`;
- persistent SELinux Booleans;
- AVC investigation with `ausearch`;
- firewalld zones, sources, services, ports, runtime/permanent state;
- SELinux port labeling with `semanage port`;
- integrated Apache + SELinux + firewalld recovery.

Safety rules:

- never disable SELinux;
- never remove SSH firewall access;
- never move the management interface between zones;
- no `audit2allow`/local-policy shortcut in reference solvers;
- all temporary SELinux/firewall/httpd changes are cleaned up by `lab finish`.

Automated regression count grows from 77 to 86 labs.
Curriculum count including the two OBJ09 manual-console drills grows from 79
to 88 items.
