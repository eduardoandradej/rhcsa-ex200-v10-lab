# v1.5.1 — OBJ09 reference-solver stdin hotfix

The first Objective 09 runtime regression exposed a reference-harness defect.

The automated OBJ09 solvers invoked:

```bash
ssh -n servera 'bash -Eeuo pipefail -s' <<'EOS'
...
EOS
```

`ssh -n` redirects SSH standard input from `/dev/null`. Because the solution
body was also supplied through a here-document on standard input, the remote
`bash -s` received no commands. SSH exited successfully, so the integration
runner reported `OK: reference solution`, but no answer files were created.
The state-based grader then correctly returned 0%.

The fix removes `-n` from all five OBJ09 solvers that intentionally feed a
script through stdin:

- obj09-01
- obj09-02
- obj09-03
- obj09-05
- obj09-07

This does not revert the earlier rule that some nested/background SSH calls
need `ssh -n`; it only forbids using `-n` when stdin itself carries the remote
script.

The OBJ09 release gate now rejects the invalid `ssh -n ... <<EOS` combination.
No student-facing task or grader contract changed.
