# v1.8.4 — OBJ12-06 protected report evidence hotfix

The `obj12-06` reference solution correctly created `/srv/final12` as
`root:opsfinal12` mode `2770`, and the `operator12` user successfully wrote
the two report files.

The engineering reference runner then tried to read those files as the
unprivileged `student` user. Because `student` is not a member of
`opsfinal12`, directory traversal was correctly denied.

v1.8.4 changes only the engineering inspection/evidence path:

- the reference solution collects report evidence with `sudo cat`;
- the grader inspects the two protected report files with `sudo -n cat`.

The learner task, ownership, group membership, directory mode, script, AutoFS
configuration, and cron requirement are unchanged.
