# v1.4.9 — release-gate grep matcher hotfix

The v1.4.8 validation output exposed `grep: conflicting matchers specified`
while the affected gate still printed `OK`.

Four OBJ08 release gates combined GNU grep `-P` and `-E`, which are mutually
exclusive matcher modes. In pipeline/`|| true` contexts, that command error
could be misread as "no match" and produce a false PASS.

v1.4.9 removes the conflicting `-E` option from every affected gate and adds a
meta-gate that rejects future OBJ08 release gates combining `-P` and `-E`.

No lab state, storage workflow, grader, or student-facing exercise changes.
