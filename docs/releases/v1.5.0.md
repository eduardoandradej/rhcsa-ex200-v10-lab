# v1.5.0 — Objective 09 Boot, GRUB & Recovery

Adds Objective 09 with seven learning items.

Automated/runtime-gradeable:

- obj09-01 boot, kernel, and GRUB inventory;
- obj09-02 persistent kernel arguments with `grubby`;
- obj09-03 systemd default target;
- obj09-05 safe fstab recovery;
- obj09-07 integrated boot/recovery challenge.

Manual console drills:

- obj09-04 rescue/emergency boot;
- obj09-06 root access recovery.

The manual boundary is intentional. The bastion has no privileged libvirt
host-control path, and the project will not widen hypervisor privileges only to
automate pre-SSH GRUB interaction. RHEL 10 recovery behavior should also be
repeated in RHLS Premium on a native RHEL 10 lab.

No automated OBJ09 setup or reference solver is allowed to reboot `servera`,
enter rescue/emergency, use `init=/bin/bash`, or target `/dev/vda`.

`obj09-05` is a safe adaptation of boot-time fstab repair: the broken initial
entry uses `nofail` so an accidental reboot does not strand the VM. The final
graded state removes `nofail`.

Automated regression count after this release: 77 labs.
Curriculum count including manual console drills: 79 items.
