# v1.4.3 — OBJ08 protected-disk release-gate hotfix

Corrects a false failure in the OBJ08 protected-system-disk release gate.

## Cause

In v1.4.1, the storage safety implementation was refactored so that the actual
allowlist and `/dev/vda` deny rule live in the reusable helper:

`ansible/files/rhcsa-storage-guard`

The old release gate still searched for that rule inside
`ansible/prepare-objective08.yml`, where it no longer belongs.

The safety behavior itself was intact; the static test was checking the old
implementation location.

## Fix

The protected-disk release gate now verifies three independent properties:

1. no destructive OBJ08 student/reference command targets `/dev/vda`;
2. the reusable storage guard explicitly hard-denies `/dev/vda` and its
   children;
3. `prepare-objective08.yml` actively probes `/dev/vda` and requires that probe
   to be rejected.

No storage workflow or lab requirement changed.
