# v1.2.3 — OBJ06 keyfile grader permission hotfix

Corrects `obj06-05`.

## Cause

NetworkManager system connection files under:

`/etc/NetworkManager/system-connections/`

are intentionally protected and normally root-readable only.

The remote grader runs as `student`. It attempted to inspect the training
`.nmconnection` file directly with `Path.read_text()`, which raised
`PermissionError` before the grader could return JSON.

## Fix

The grader now:

- keeps running as `student`;
- uses `sudo -n cat` only for privileged inspection of the root-only keyfile;
- continues to validate persistent state with `nmcli`;
- continues to validate runtime state with `ip`.

File permissions are not weakened.

A release gate now rejects a regression to direct unprivileged reading of the
NetworkManager keyfile.
