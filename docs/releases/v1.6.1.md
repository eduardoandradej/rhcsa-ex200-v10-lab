# v1.6.1 — OBJ10-05 bounded AVC analysis hotfix

Runtime testing exposed a local-lab performance problem in `obj10-05`.

The exercise correctly produced a real SELinux denial:

- SELinux remained enforcing;
- Apache returned HTTP 403 for `/srv/avc10/index.html`;
- the audit log contained AVC records from `httpd_t` to `default_t`.

However, on the long-lived local VM, `ausearch -m AVC -ts recent` could spend
too long scanning the accumulated audit log. A five-second bounded diagnostic
confirmed the command could time out even while the relevant AVC records were
already present near the end of `/var/log/audit/audit.log`.

v1.6.1 keeps the real denial and the `ausearch` skill, but makes the lab
deterministic:

1. setup triggers the real denial;
2. setup captures only a bounded tail of the live audit log containing this
   lab's `/srv/avc10/index.html` AVC records;
3. the student analyzes that real sample with
   `ausearch -if input/avc.audit -m AVC`;
4. the final repair remains `semanage fcontext` + `restorecon`.

The RHEL/RHLS live-log command `ausearch -m AVC -ts recent` remains documented
as the normal command on a clean training system. The adaptation is limited to
the long-lived local automation VM.
