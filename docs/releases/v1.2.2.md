# v1.2.2 — OBJ06 IPv6 grader hotfix

Corrects the persistent IPv6 checks in:

- obj06-04
- obj06-08

## Cause

The graders queried connection fields with `nmcli -g`.

`-g` uses terse output. In that output mode, special characters such as the
colon separators in IPv6 values can be escaped. The runtime checks based on
`ip -6 addr` were already correct, which is why the lab could show:

- IPv6 present in runtime
- IPv6 ping successful
- persistent IPv6 check failed

## Fix

The graders now query NetworkManager with:

`nmcli --escape no -g ...`

so IPv6 values are compared in their normal textual form.

No learner task or reference solution needed to change.
