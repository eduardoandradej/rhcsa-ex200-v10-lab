# v1.2.1 — OBJ06 routing contract hotfix

Corrects `obj06-03`.

`ipv4.never-default=yes` and `ipv4.gateway` must not be required at the same
time. NetworkManager treats them as conflicting concepts: a profile marked
never-default must not supply the standard default gateway.

The lab now requires:

- primary IPv4 `10.66.3.20/24`
- secondary IPv4 `10.66.3.120/24`
- `ipv4.never-default=yes`
- empty `ipv4.gateway`
- no default route through `ex200a`
- successful connectivity to the directly connected peer `10.66.3.254`
