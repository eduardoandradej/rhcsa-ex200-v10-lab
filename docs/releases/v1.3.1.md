# v1.3.1 — OBJ07 tmpfiles grader permission hotfix

Corrects `obj07-02`.

The exercise intentionally creates `/run/rhcsa-momentary` as `root:root` with
mode `0700`. The remote grader runs as `student`.

The previous grader used Python `Path.exists()` on
`/run/rhcsa-momentary/stale.txt`. Because `student` cannot traverse a root-only
`0700` directory, the check raised `PermissionError` before the grader could
return JSON.

The grader now checks the required final state with:

`sudo -n test ! -e /run/rhcsa-momentary/stale.txt`

The directory permissions remain unchanged.
