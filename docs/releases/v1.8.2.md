# v1.8.2 — OBJ12-03 non-interactive XFS growth hotfix

The reference solver used `lvextend -r` before the XFS file system was mounted.
On this RHEL environment, LVM requested interactive confirmation to mount and
grow the file system, so the here-document was consumed as prompt input and
the reference solution failed.

v1.8.2 keeps the intended LVM/XFS growth task but makes it deterministic:

1. extend the LV with `lvextend -L +512M`;
2. mount the file system through the configured `/etc/fstab`;
3. grow XFS explicitly with `xfs_growfs /srv/data12`.

No grader or lab objective changed.
