# v1.4.4 — OBJ08 bounded LVM setup hotfix

Corrects an `obj08-09` start that exceeded the lab runner's 180-second
playbook timeout.

The setup previously grouped partitioning, an unbounded `udevadm settle`,
PV/VG/LV creation, XFS formatting, mounting, and marker creation in one opaque
shell task. If any step stalled, the caller could only report a global timeout.

The setup now:

- uses `partprobe` after partition-table changes;
- waits specifically for `/dev/vdc1` with a 15-second bound;
- creates PV, VG, LV, XFS, mount point, mount, and marker as separate Ansible
  tasks;
- therefore identifies the exact failing stage instead of consuming the entire
  180-second runner timeout.

`obj08-10` receives the same bounded device-node preparation proactively.

No student-facing storage objective or grader requirement changed.
